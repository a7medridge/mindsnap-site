Privacy Policy

Last updated: 12 October 2026

MindSnap Uploader is a private tool used only by the owner of the MindSnap YouTube channel.

What it accesses

With the channel owner's permission, the tool uses the YouTube Data API with the single permission "upload videos" (youtube.upload) to upload the owner's own videos to the owner's own channel.

What it collects

The tool does not collect, store, or share personal information about anyone. It has no user accounts other than the channel owner's own Google sign-in, and it does not use cookies, analytics, or advertising.

Stored data

The only data kept is the owner's own Google authorization token, stored privately so uploads can run automatically. It is never shared with third parties. The owner can revoke it at any time at myaccount.google.com/permissions.

Contact

Questions can be sent through the MindSnap YouTube channel.
